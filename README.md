# Deep Learning Stuff

Kumpulan tugas dan eksplorasi Deep Learning menggunakan Python dan Google Colab.

## Contents

| File | Deskripsi |
|------|-----------|
| Tugas_Deep_Learning_CNN.ipynb | Tugas CNN — klasifikasi gambar dengan CIFAR-10, Fashion-MNIST, dan Flowers dataset |

## Topics Covered

- **Soal 1** — Eksplorasi data & preprocessing (CIFAR-10)
- **Soal 2** — Membangun CNN dari nol
- **Soal 3** — Regularisasi: Dropout & Batch Normalization
- **Soal 4** — Visualisasi training curve, Confusion Matrix, F1-score
- **Soal 5** — Augmentasi data (Fashion-MNIST)
- **Soal 6** — Transfer Learning dengan VGG16 + Fine-tuning (Flowers dataset)
- **Soal 7** — Perbandingan & analisis akhir
- **Bonus** — Grad-CAM visualization

## How to Run

1. Buka notebook di Google Colab:  
   [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/alvistya/deep-learning-stuff/blob/main/Tugas_Deep_Learning_CNN.ipynb)

2. Aktifkan GPU: Runtime → Change runtime type → T4 GPU

3. Jalankan semua cell: Runtime → Run all
